SMART PUBLIC TRANSPORT PLATFORM

The Future of
Smart Bus Transportation

RouteLK is an IoT-based smart public transportation management system that provides real-time bus tracking, passenger occupancy monitoring, and cloud-connected transport solutions.

The Problem

Current challenges faced by public transportation users

No Real-Time Tracking

Passengers cannot know the current location of buses or expected arrival time.

Unknown Passenger Capacity

Passengers have no information about bus crowd levels before boarding.

Unpredictable Waiting Time

Passengers spend unnecessary time waiting at bus stops.

Fragmented Systems

Existing apps provide only isolated features instead of a single, unified platform.

Reduced Reliability

These limitations decrease the convenience, trust, and appeal of public transport.

Our Solution

RouteLK is an IoT-based Smart Bus Tracking and Passenger Assistance System designed to modernize public transport by integrating embedded hardware, cloud services, and mobile applications into one platform. Unlike existing solutions that provide only individual services, RouteLK brings together real-time bus tracking, passenger occupancy monitoring, A/C bus seat booking, emergency notifications, and transport information within a single mobile application.


Each bus is equipped with an ESP32-based embedded device that continuously collects GPS location, passenger occupancy, and emergency status using onboard sensors. The collected data is securely transmitted to AWS Cloud through WiFi or the cellular network (optionally), where it is processed, stored, and synchronized with the mobile application in real time. This enables passengers to access accurate transportation information while allowing transport operators to efficiently monitor and manage their fleet.
