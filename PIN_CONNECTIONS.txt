ESP32 Pin Connections
=====================



1b) Ultrasonic Passenger Counter Module (separate)
- GPIO5  -> Ultrasonic TOP TRIG
- GPIO18 -> Ultrasonic TOP ECHO
- GPIO19 -> Ultrasonic BOTTOM TRIG
- GPIO21 -> Ultrasonic BOTTOM ECHO

2) GPS Module (UART2)
- GPIO16 -> GPS TX to ESP32 RX2
- GPIO17 -> GPS RX from ESP32 TX2

3) Emergency Button Module
- GPIO25 -> Push button input (configured as INPUT_PULLUP)
  Wiring note: connect button between GPIO25 and GND.

Ultrasonic Sensor 3
TRIG → GPIO26
ECHO → GPIO34

Ultrasonic Sensor 4
TRIG → GPIO27
ECHO → GPIO35

Recommended GSM wiring (UART1)
GSM TX → GPIO14 (ESP32 RX)
GSM RX → GPIO13 (ESP32 TX)

Push button 2
Recommended
GPIO23 → Push button (INPUT_PULLUP)








Notes
-----
- Board: ESP32 DOIT DevKit V1
- Pin usage extracted from source files in src/.
